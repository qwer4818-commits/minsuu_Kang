01 · Motivation

왜 이 문제를 풀어야 하는가?

한국의 공식 재활용률은 높게 발표되지만, 실제 재활용률은 그에 못 미친다는 연구가 잇따르고 있습니다. 원인의 큰 부분은 잘못된 분리수거 — 사람이 매번 정확히 구분하기 어렵기 때문입니다.

02 · Dataset & Method

데이터와 모델

데이터 수집

총 1,057장의 원본 이미지를 3가지 경로로 수집한 뒤, 증강을 통해 클래스당 300장씩 균형 데이터셋을 구성했습니다.

Data Sources

  • Kaggle Garbage Classification877장
  • 직접 촬영 (재활용 수거장)151장
  • 웹 수집 (glass · styrofoam)29장
  • 총 원본 이미지1,057장

Preprocessing

  • 중복 제거imagehash
  • 리사이즈224×224
  • 증강flip · rotate · brightness
  • Split70/15/15

모델 아키텍처

사전학습 모델 없이 처음부터 CNN을 직접 설계했습니다. 3개의 컨볼루션 블록과 FC 레이어 구조입니다.

Input 3×224×224 → Conv 32 · ReLU · Pool → Conv 64 · ReLU · Pool → Conv 128 · ReLU · Pool → FC 512 · Dropout 0.5 → 6 Classes

Training 설정

Hyperparameters

  • Epochs50
  • Batch size32
  • Learning rate0.001
  • OptimizerAdam
  • LossCrossEntropy

Data Balance

원본 데이터셋은 클래스 간 불균형이 심했지만, 증강을 통해 클래스당 300장으로 균형을 맞춘 뒤 학습했습니다.

03 · Experiments & Results

실험 결과

50 epoch 학습 결과, 검증셋에서 58%의 정확도를 달성했습니다. 클래스별 성능 차이가 크게 나타났으며, 시각적으로 유사한 클래스 간 혼동이 주된 오류 원인이었습니다.

04 · Discussion & Applications

배운 점 & 활용 가능성

배운 점

  • • 데이터 수집이 가장 오래 걸렸다. 모델 학습보다 깨끗한 데이터를 모으는 일이 훨씬 어려웠다.
  • • 클래스 불균형은 증강으로 어느 정도 해소되지만, 다양성 부족은 해결 안 됨.
  • • 시각적으로 비슷한 클래스(투명한 plastic vs glass)는 단순 CNN으로 구분이 어렵다.

향후 개선

  • • Transfer Learning (ResNet, EfficientNet)으로 baseline 강화
  • • 클래스당 1,000장 이상 다양한 조명·각도 데이터 수집
  • • 모바일 앱 형태의 실시간 분류 데모 배포
  • • 멀티모달 (RGB + 무게/재질 센서) 확장

활용 시나리오

공공 분리수거장의 스마트 쓰레기통에 탑재하여 시민이 쓰레기를 투입하는 순간 자동 분류하고, 잘못된 투입은 즉시 피드백을 주는 시스템으로 확장 가능합니다. 가정용 앱 형태로 보급되면 분리수거 교육에도 활용할 수 있습니다.
